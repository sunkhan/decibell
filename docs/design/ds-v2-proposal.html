What actually changed. The titlebar now sits at --canvas while the server bar sits at --surface-0, so there is a visible seam instead of one unbroken slab. Chrome surfaces get a --gradient-chrome wash and an inset top highlight (--shadow-lip) — that's the "panel catching light from above" cue, and it costs nothing at runtime. The active channel row gains a left rail marker so selection reads without relying on a fill wash alone. Streaming turns violet.
No backdrop-filter on any of this. Real glass would force Chromium to snapshot what's behind the bar every frame. The look here is a static gradient plus an inset highlight — rasterised once, zero per-frame cost. Blur is reserved for transient layers (popovers, modals) that don't repaint underneath.
02

Streaming gets its own colour

This is the most opinionated call in v2, so judge it hard. Today, "live" borrows the azure accent — which means a stream tile that is selected and a stream tile that is broadcasting look the same. Screensharing is the differentiating feature of this app; it should have its own signal. Red was unavailable (error already owns it, and "you are live" is not a failure), so v2 uses violet — adjacent to azure on the wheel, so it harmonises, but unmistakable at a glance.

Surfaces become an elevation model

04

The accent becomes a system

05

Elevation

v1's shadows were single soft blurs. v2 layers a tight contact shadow under a wide ambient one — that's the difference between "floating" and "smudged" — and bakes the hairline ring in, so a floating surface never needs a separate border class.

06

Type gets semantic names

The sizes are the ones v1 settled on and they're right — this isn't a re-scaling. The problem is they're written as text-[13px] in 296 places, so a size carries a pixel count instead of an intent. v2 adds named tokens with paired line-heights. Tailwind's own text-xs/text-sm are left untouched, so none of the 57 existing named-size call sites shift.

07

What this costs

The layout is untouched, so regression risk is concentrated in the token layer — which every component already reads through. Beyond tokens, the work is the cleanup v1 left behind.
