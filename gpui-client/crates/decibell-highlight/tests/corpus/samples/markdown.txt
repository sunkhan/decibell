Reading Room
============

A small, self-hosted catalogue for a shared bookshelf.
It runs on one machine and needs no account.

# Getting started

Install it with *one* command, then open the _local_ page. The **server**
keeps __everything__ in a single file; ***back it up***. Use `rr serve`
to start it, or ``rr serve --port `8080` `` if the default port is taken.
A line that ends with two spaces  
breaks here, and a backslash\
breaks here too.

Escapes: \*not emphasis\*, \_nor this\_, \# not a heading, \[not a link\], 2 \* 3 = 6, a \\ backslash.

## Install

1. Download the archive from <https://example.org/downloads>.
2. Unpack it:
   ```sh
   tar -xzf reading-room.tar.gz && cd reading-room
   ```
3. Run the server.
   1. On Linux: `./rr serve`
   2. On Windows: `rr.exe serve`
10. Write to <hello@example.org> if it fails.

- Books
  - Titles, authors and *tags*
  - Covers (PNG or JPEG)
    * up to 2 MB each
    * stored next to the database
- Shelves
+ Loans, with [due dates](#loans)
* [ ] Wish list (planned)
* [x] Search

### Configuration

The settings live in `config.toml`. See the [reference][config-ref] and
the [FAQ]; the [sample file][1] is a good start, as is [this page](<docs/my config.md>).

[config-ref]: https://example.org/docs/config "Configuration reference"
[FAQ]: ./docs/faq.md
[1]: <https://example.org/sample config.toml> 'Sample file'

```toml
[server]
port = 8080          # change if taken
data = "./data"
```

#### An example client ####

```js
// Fetch the first page of books.
const res = await fetch(`/api/books?page=${page}`, { headers: { Accept: "application/json" } });
const { items = [], total } = await res.json();
console.log(`${items.length} of ${total}`, items.map((b) => b.title));
```

~~~python
import json
from urllib.request import urlopen

def books(page: int = 1) -> list[dict]:
    """Return one page of books."""
    with urlopen(f"http://localhost:8080/api/books?page={page}") as res:
        return json.load(res)["items"]
~~~

Loans
-----

Term
: A definition, in the flavours that support it.

A loan has a due date.[^1] Late loans turn ~~red~~ **orange** in the list.
Visit http://example.org/loans or www.example.org for the hosted demo.

[^1]: Fourteen days by default. NOTE: the limit is per shelf.
